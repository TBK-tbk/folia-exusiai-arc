# 更新日志

## 1.3.0

- 新增 **滚轮翻歌词**：鼠标悬停左侧歌词区时，滚轮上下翻看整首歌的歌词
- 歌词改为 **全量渲染**：一首歌的所有行一次性铺在圆弧上，不再只渲染当前行附近
- 手动翻看时切歌 **不再闪回当前行**；5 秒无操作自动平滑回到跟随播放
- 新增两个 **背景维克托法阵**（52%/15%、25%/82%），静态、低透明度、与主法阵错开

## 1.2.0

- 新增 **背景径向渐变呼吸**：最底层径向渐变随低频提亮，透出暗红柔光
- 新增 **齿轮刻度分层颜色**：内暗红 / 中橙红 / 外暖金，音量越大分层越明显
- 新增 **刻度相位差旋转**：内中外三圈差速转动（含反向），低频加速
- 新增 **星尘漂移**：背景暗金星尘缓慢漂浮，鼓点被吹散后回归
- 新增 **歌词辉光呼吸** **文字弹性缩放** **低频径向光晕** **圆弧流光拖尾** **刻度旋动**
- 所有设置项补齐中英双语说明
- 修复设置项 `description` 被误嵌进 `label` 的问题

## 1.1.0

- 新增 **时序刻度脉动** **刻度环形扫光**
- 新增 **仿真鼓面**：低频鼓点让圆弧与歌词弹性下陷再回弹
- 中央法阵内的维克托线稿改为引用线稿原图，绕圆心匀速旋转

## 1.0.0

- 首个版本：圆弧歌词排布、齿轮刻度盘、能天使立绘、光环进度环
- 支持歌词自动换行（中英分别按语义断行）
- 支持双语歌词（原文 + 译文）
