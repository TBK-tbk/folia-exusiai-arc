# 动感效果详解

本文逐条说明 12 组音频联动效果：**它做什么、听什么信号、参数怎么调、想关掉注释哪里**。

> 所有效果都是"叠加层"：只读取音频、只写自己那几个元素的属性，
> 不改动圆弧排布、文字样式、齿轮几何与立绘位置。任何一项关掉都会自动复位、不留残影。

---

## 通用触发机制

模组里有两个共用的节拍信号：

```js
// 低频起音：瞬时值高于约 1 秒的慢均值
drum.sm += (bass - drum.sm) * 0.018;
const tr = bass - drum.sm;
if (tr > 0.10 && cooldown === 0) { /* 命中一次 */ }

// 总能量：ctx.audio.getPower()，0..1
```

- **低频** 用于所有"鼓点"类效果（鼓面、脉动、星尘被吹散、文字缩放、光晕）
- **总能量** 用于"持续"类效果（辉光呼吸、旋动加速、相位差）
- 所有驱动量都过了一遍低通或包络，所以不会跟着高频噪声乱跳

## 1. 仿真鼓面 `drum`

| 项 | 值 |
|---|---|
| 开关 | `drum`，**默认开启** |
| 参数 | `drumStrength` 0–2（默认 1.00） |

**做什么**：低频鼓点命中时，整条歌词弧和齿轮盘一起向下"陷"一下，然后阻尼回弹。

**怎么实现**：`dent` 是一个弹簧量，命中时给负向速度，之后按 `vel += -150·dent·dt`、
`vel *= exp(-11·dt)` 收敛。歌词层 `translateY(-dent·26px)`，齿轮盘 `translateY(-dent·12px)` 并轻微缩放。

**调法**：1.00 是调好的基准；想要更"重"可以到 1.4，超过 1.6 会显得画面在抖。

**注释关闭**：搜 `const stepDrum` 与 `// ===== [MOD] 背景呼吸` 前的 `dent` 使用处。

## 2. 时序刻度脉动 `tickPulse`

| 项 | 值 |
|---|---|
| 参数 | `tickStrength` 0–2（0.60）、`tickDecay` 0.2–3（1.00） |

**做什么**：每次鼓点，背景里 5 圈同心刻度环从内向外依次亮一下，越外圈亮得越晚。

**怎么实现**：五条环各自延迟 `0.055s`，亮度 `exp(-decay·age·2.2)`，像涟漪一样扩散。

**调法**：`衰减速度` 调到 2 以上会变成"闪一下就没"，0.5 左右是缓慢余辉。

---

## 3. 刻度环形扫光 `sweep`

| 项 | 值 |
|---|---|
| 参数 | `sweepBright` 0–2（0.70）、`sweepSpeed` 0–3（1.20） |

**做什么**：一根极细的暖金光弧沿背景刻度环顺时针扫过，途经的刻度会被短暂提亮。

**怎么实现**：光弧是半径 `R×1.06` 的一小段 `9°` 圆弧，每帧 `rotate`；
72 根刻度按与扫光的角度差做 `exp(-Δ²/2σ²)` 提亮，σ≈7°。

**调法**：速度 0 会停住但刻度仍保持提亮；0.6 以下偏"慢门"，1.5 以上偏"雷达"。

---

## 4. 歌词辉光呼吸 `glowBreath`

| 项 | 值 |
|---|---|
| 参数 | `glowRange` 0–2（0.70）、`glowBright` 0–2（0.80） |

**做什么**：当前句的外发光跟着总音量起伏 —— 副歌时散开变亮，安静段收窄变淡。

**怎么实现**：只改当前句 `.fill` 的 `filter`，叠两层 `drop-shadow`，半径与透明度都由 `power` 驱动。

**注意**：只作用于**当前高亮句**，其余歌词保持原样。

---

## 5. 刻度旋动 `ringSpin`

| 项 | 值 |
|---|---|
| 参数 | `ringSpeed` 0–1（0.25）、`ringDrive` 0–1（0.40） |

**做什么**：背景的刻度圆环缓慢自转，音量越大转得越快。

**怎么实现**：`spd = 6·ringSpeed + power·ringDrive·90`（度/秒），直接 `rotate` 整个刻度组。

**调法**：`音频驱动权重` 设 0 就是纯匀速钟表感；设 1 时鼓点会把转速拉得很快。

---

## 6. 文字弹性缩放 `textPulse`

| 项 | 值 |
|---|---|
| 参数 | `textAmp` 0–0.3（0.08）、`textDamp` 2–15（8.0） |

**做什么**：鼓点命中瞬间，当前句轻微放大再弹回。

**怎么实现**：用 CSS 独立的 `scale` 属性（不与原有 `transform` 冲突），
弹簧参数 `-160·scale` 回正、`exp(-damp·dt)` 阻尼。

**调法**：`幅度` 超过 0.15 会开始影响阅读；`阻尼` 越大回弹越干脆，2 左右会有明显"果冻感"。

---

## 7. 低频径向光晕 `radialGlow`

| 项 | 值 |
|---|---|
| 参数 | `radialRadius` 0–2（0.80）、`radialAlpha` 0–1（0.30） |

**做什么**：低频命中时，一圈暗红光晕从圆弧中心向外散开、慢慢消失。

**怎么实现**：一个 `radial-gradient` 圆，`scale` 从 240px 扩到 240+620·radius，
透明度 `alpha·(1 - age/1.25)` 线性衰减。

**注意**：层在歌词之下，不会压住文字。

---

## 8. 圆弧流光拖尾 `arcTrail`

| 项 | 值 |
|---|---|
| 参数 | `trailLength` 0–2（0.60）、`trailBright` 0–2（0.70） |

**做什么**：一条暖金光带沿歌词所在的弧线滑动，后面拖着渐隐的尾巴，节拍越强越亮。

**怎么实现**：路径就是歌词那段圆弧，用 `stroke-dasharray` 造拖尾、
`stroke-dashoffset` 让它移动，速度 `len/6·(0.6 + beat)`。

---

## 9. 刻度相位差旋转 `phaseRot`

| 项 | 值 |
|---|---|
| 参数 | `phaseDiff` 0–0.6（0.15）、`phaseDrive` 0–1（0.30） |

**做什么**：内、中、外三圈刻度以**不同速度**转动（中间那圈反向），低频越强差速越明显。

**怎么实现**：

```js
const base = 3 + bass * 46 * phaseDrive;
const speeds = [base * (1 - diff), -base * (0.45 + diff), base * (0.75 + diff * 1.4)];
```

**调法**：`转速差` 为 0 时三圈同速（等于没开）；0.4 以上会明显"打架"，机械差速器味道最足。

## 10. 星尘漂移 `stardust`

| 项 | 值 |
|---|---|
| 参数 | `starCount` 0–80（25）、`starSpeed` 0–1（0.20） |

**做什么**：背景里一层极细的暗金星尘缓慢漂浮；鼓点命中时被向外吹散，之后缓缓回到原位。

**怎么实现**：每个点有基准坐标与两个相位，平时按双正弦漂移；
命中时 `push` 加 9，`exp(-2.2·dt)` 衰减，位移 `(base - 原点) · push/100`。

**注意**：星尘只在左侧与中部生成（`x 4%–62%`），不会盖到立绘上。

---

## 11. 背景径向渐变呼吸 `bgBreath`

| 项 | 值 |
|---|---|
| 参数 | `bgStrength` 0–2（0.50）、`bgWeight` 0–1（0.60） |

**做什么**：最底层背景的径向渐变中心跟着低频变亮/变暗，透出暗红柔光。

**怎么实现**：`bgLp` 低通（0.045，约 0.4 秒时间常数），
透明度 `0.10 + 0.72·k`，渐变圆心的坐标由圆弧几何换算成百分比。

**注意**：这是**最底层**（刻度线之下），不会影响任何线条的清晰度。

---

## 12. 齿轮刻度分层颜色 `ringTint`

| 项 | 值 |
|---|---|
| 参数 | `tintShift` 0–2（0.40）、`tintDrive` 0–1（0.35） |

**做什么**：刻度分成三层颜色 —— 内层暗红、中层橙红、外层暖金；音量越大，三层差距越明显。

**怎么实现**：三层各自在"原暗金 → 目标色"之间按 `t` 插值，
`t = (0.10 + bgLp·tintDrive) · tintShift`，所以安静时完全回到原本的统一暗调。

**注意**：外层那 72 根刻度和「刻度环形扫光」共用同一个 `stroke`，
两者同时开启时以扫光为准（代码里有 `!settings.sweep` 的互斥判断）。

## 关掉某一项的最快办法

每个效果在 `client.mjs` 里都有成对的注释标记：

```js
// ===== [MOD] 效果名 · 每帧 =====
...
// ===== [MOD] 效果名 · 每帧结束 =====
```

1. **直接关开关** —— 首选，所有效果都有复位逻辑，关掉即干净。
2. **注释代码** —— 把 `[MOD]` 块整段 `/* */` 掉；
   注意 `readSettings` 里对应的读取行也一起注释，避免残留配置项。
3. **从面板隐藏** —— 删掉 `settings` 数组里对应的条目即可，值仍会保留在本地。
